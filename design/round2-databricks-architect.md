## Part 2. Catalog management

**Verified read-only:** you are in group `admins`; the group `_workspace_admins_presales_us_east_2_...` holds `CREATE_CATALOG` on the metastore (also CREATE_EXTERNAL_LOCATION/STORAGE_CREDENTIAL/SHARE). Other catalogs are colleagues' or `precisely_db`/`precisely_dev` (not ours to write).

### Decisions
1. **Create a NEW dedicated catalog `address_fabric`** (variable `${catalog}`); dev = `address_fabric_dev` (same schema/table names, different catalog variable in the DAB target). Why not `geomazerunner`: different product, schemas `bronze/silver/ops` already used by the geocoder, so tables would mix; grants are per-catalog/schema, and consumers of address-change data should not inherit access to geocoding data; NJ-sensitive data wants one clearly bounded owner/retention domain. Why not `precisely_db/dev`: not ours. Cost of a new catalog is zero. **Fallback** if CREATE CATALOG fails: schemas `adf_bronze/adf_silver/adf_gold/adf_ops` inside `geomazerunner` (never reuse its existing schemas).
2. **Storage:** default (metastore root), no external location. A dedicated managed location (own S3 prefix/bucket) isolates PII and simplifies audited erasure, but needs an external location + bucket + IAM work and **cannot be changed after the catalog exists**. Recommendation: accept the root (same as `geomazerunner`). **One question for Mayank:** is that acceptable, or do you want a dedicated bucket before the PII lands?
3. **Ownership:** create as you now (needed to run the baseline); later a dedicated service principal `sp-adf-usa-pipeline` owns schemas/tables and runs the job (job `run_as`); you stay catalog owner/admin. Workspace SPs listed are unrelated projects - do not reuse.
4. **Grants (later, not now):** consumers get `USE CATALOG`, `USE SCHEMA` on `gold` + `SELECT` on gold views only; SP gets `USE`/`CREATE TABLE`/`MODIFY`/`SELECT` on bronze/silver/ops; no group sees bronze/silver (full PII + baseline). Principals are account groups, to be named (only `admins`/`users` exist in this workspace).
